# 📈 Real-Time Multi-Stock Price Prediction using Artificial Neural Networks (ANN)

## 🚀 Project Overview

This project is a Machine Learning and Deep Learning-based stock market prediction system that predicts future stock prices of multiple companies using Artificial Neural Networks (ANN). The model analyzes historical stock market data and learns patterns to forecast future price movements.

The application provides a user-friendly interface for selecting stocks, viewing historical trends, and generating real-time predictions.

---

## 🎯 Features

✅ Real-time stock data analysis

✅ Multi-stock prediction support

✅ Artificial Neural Network (ANN) based forecasting

✅ Data preprocessing and feature engineering

✅ Interactive visualization of stock trends

✅ User-friendly interface

## ⚙️ How It Works

1. Historical stock data is collected using Yahoo Finance.
2. Data is cleaned and preprocessed.
3. Important features are extracted.
4. ANN model is trained on historical data.
5. The trained model predicts future stock prices.
6. Results are displayed through a Streamlit dashboard.

## 🔧 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Real-Time-Multi-Stock-Prediction.git
```

Move into the project directory:

```bash
cd Real-Time-Multi-Stock-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
